# Seal & Sentence

### Duty, conscience, and a border on the brink.

A medieval border-inspection game about documents, difficult decisions, and the people behind them.

| Status | Built with | Repository purpose |
| :--- | :--- | :--- |
| In development · Steam page live | Unity · C# | Public project showcase |

## The experience

- Inspect travel papers, seals, and suspicious cargo.
- Question travelers and respond to changing royal orders.
- Make decisions with consequences beyond the checkpoint.
